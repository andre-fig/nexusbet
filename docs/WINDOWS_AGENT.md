# Collector-agent neste Windows

O Windows 11 deste PC executa apenas Superbet, Blaze e EstrelaBet por HTTP. Bet365 e Betano exigem o `local-cdp` suportado no macOS e ficam desabilitados aqui. O agent envia scopes por HTTPS ao server no Railway; não recebe `DATABASE_URL` e não acessa PostgreSQL. O token e a outbox ficam em `%LOCALAPPDATA%\NexusBet`, fora do checkout. O server continua responsável pelas transações SQL.

`scripts/windows-agent-reconcile.ps1` consulta `main` a cada execução. Se o SHA mudou, clona a nova versão para uma release isolada, executa `npm ci`, `typecheck`, `format:check`, `build` e `npm test`, solicita shutdown do agent atual por marker e troca `current.txt`. Uma falha de GitHub ou de validação conserva a versão anterior. O mesmo script reinicia o agent caso o processo tenha saído. Falhas de internet durante a coleta são tratadas pela outbox e pelo retry do próprio agent; quando GitHub voltar, o próximo ciclo atualiza.

A tarefa `NexusBetCollectorAgent` roda a cada minuto e no login da conta Windows. Ela usa `-MultipleInstances IgnoreNew` e o script também usa um mutex para evitar atualizações simultâneas. `agent.json`, `outbox`, `releases`, `current.txt`, `agent.pid` e logs ficam em `%LOCALAPPDATA%\NexusBet`. O supervisor é copiado para esse diretório, de forma que a própria atualização do checkout não altere um script em execução. Depois de mudar o supervisor no repositório, copie a nova versão e valide a tarefa antes de considerá-la ativa.

Esta tarefa usa o token interativo da conta. Ela inicia automaticamente **após o login**, mas não cobre o intervalo entre boot e login. Para execução antes do login seria necessária uma tarefa ou serviço sob conta de serviço, com instalação elevada e caminhos fixos fora do perfil interativo. O runtime atual de três providers HTTP não exige sessão gráfica, mas o acesso a GitHub e ao diretório privado precisa ser preservado para essa conta. Não confunda tarefa criada com validação de reboot, ingestão real ou recuperação de falha.

Para inspecionar localmente, use `Get-ScheduledTask -TaskName NexusBetCollectorAgent`, o log `%LOCALAPPDATA%\NexusBet\logs\supervisor.log`, os logs `agent-*.log` e o endpoint autenticado `GET /internal/agents`. Não imprima `agent.json` ou variáveis do Railway em logs. A outbox mantém mensagens pendentes durante falhas de rede, sujeita aos limites de retenção descritos em [Runtimes](RUNTIMES.md). No Windows, a gravação da mensagem faz `fsync` do arquivo antes do rename; o sistema não permite `fsync` do diretório como no macOS/Linux.
